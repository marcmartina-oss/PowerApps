# Maze Keep

A portrait, one-handed maze-building tower defense for iPhone, built in Godot 4.6.
Players shape the path monsters walk, then defend it. Free to try, one unlock, no ads.
Design: [`docs/design_doc_v2.md`](docs/design_doc_v2.md).

## What's in the game

**Campaign** — 30 levels across three worlds, each with its own look and music:
1. *The Borderlands* (farmland): basics, flyers, sappers · unlocks Frost Mage and Flame Brazier
2. *The Haunted Marsh* (swamp): water tiles, ghosts, two gates · unlocks Arcane Spire
3. *The Dragon Peaks* (mountains): shifting gates, limited walls · unlocks War Banner

Bosses close each world: the Troll King (smashes walls), the Dragon (flies), the Lich (phases and heals).
Levels 1–3 are interactive tutorials. Three stars per level, 90 in all.

**Towers** — six, each with three tiers and a choice of two tier-3 specializations:
Archer (Longbow / Volley), Stone Thrower (Boulder / Quake), Frost Mage (Blizzard / Shatter),
Flame Brazier (Inferno / Wildfire), Arcane Spire (Lightning / Void), War Banner (Rally / Bounty).
Frost + Flame on the same enemy triggers Thermal Shock. Four targeting modes.

**Enemies** — Goblin, Wolf Rider, Orc Brute, Armored Knight, Bat Swarm (flies), Sapper (smashes walls),
Slime (splits), Shaman (heals), Ghost (phases through walls), plus the three bosses.

**Modes** — Endless (three maps, waves scale forever, best wave saved), Challenges (Archers Only, No Walls,
Double Speed — unlocked by stars), a Skill Tree of permanent bonuses unlocked by total stars.

**Maze rules** — every placement shows a ghost preview of the new route; a build that would seal a gate shows
red and costs nothing; monsters reroute live mid-wave but can't be forced to double back or loop; walls
and towers refund 70%.

**Business** — levels 1–5 free, then a single non-consumable unlock (price from the App Store, $4.99 default),
Restore Purchases in Settings, no ads, no consumables. The StoreKit call sits behind `IAP` so the purchase
flow runs (simulated) on desktop too.

Everything on screen is drawn in code and every sound is synthesized at startup, so there are no art or
audio assets to license. Replace with commissioned art later without touching gameplay.

## Run it

1. Install [Godot 4.6](https://godotengine.org/download) (standard build, not .NET).
2. Open `project.godot` and press Play (F5). Mouse clicks and drags stand in for touch.

Tests (50, including bot playthroughs of levels 1, 13 and 24):
```
godot --headless --import
godot --headless --fixed-fps 60 -s res://tests/run_tests.gd
```

Content lives in `data/*.tres`, generated by `python3 tools/gen_content.py`. Tweak balance there.

## Getting it onto an iPhone

iOS builds require a Mac with Xcode. They cannot be made on Windows or Linux.

**One-time setup**
1. Join the [Apple Developer Program](https://developer.apple.com/programs/) ($99/year; a free Apple ID can
   run on your own phone for 7 days at a time). Decide which entity publishes it (an open question in the design doc).
2. Install Xcode from the Mac App Store and open it once to accept the license.
3. In Godot, run **Editor → Manage Export Templates → Download and Install**.
4. Note your **Team ID** (developer.apple.com → Account → Membership).

**Export and run on your phone**
1. In Godot open **Project → Export → iOS** (the preset already exists).
2. Set **App Store Team ID** and a real **Bundle Identifier** (currently the placeholder `com.example.mazekeep`;
   the IAP product id in `scripts/managers/iap_manager.gd` should match your App Store Connect product).
3. For a quick device test, check **Export Project Only**, export, open the generated `.xcodeproj` in Xcode,
   plug in your iPhone and press Run.
4. For TestFlight, set the release export method to App Store, then in Xcode use
   **Product → Archive → Distribute App → App Store Connect**. In [App Store Connect](https://appstoreconnect.apple.com),
   create the app record with the same bundle ID and add testers.

**Before App Store submission**
- Create the non-consumable IAP in App Store Connect (Family Sharing on) and add the
  [godot-ios-plugins](https://github.com/godotengine/godot-ios-plugins) InAppStore plugin to the export;
  `IAP` already speaks its event API.
- Enroll in the App Store Small Business Program (15% commission).
- Privacy labels: "Data Not Collected" fits (no analytics, no accounts). Game Center for Endless scores is a
  later addition.
- Screenshots for 6.9" and 6.5" iPhones (`tools/screenshots.gd` renders every screen), privacy policy URL.
